# АПОСТОЛ

Локальный учёт бюджета студии красоты: мастера и их процент, доходы, общие расходы, прибыль и выгрузки.

Сайт статический, без сборки и сервера. Цифры остаются в `localStorage` браузера под ключом `apostol_budget_v1`.

## Страницы

- `index.html` — короткое приветствие и переход к учёту
- `Калькулятор Апостол.html` — калькулятор: мастера, фильтры, доходы, расходы, отчёты, JSON и CSV

## Как открыть

Откройте `index.html` в браузере. Калькулятор доступен по ссылке «Открыть калькулятор».

Если браузер ограничивает скрипты для файлов с диска, поднимите папку как сайт:

```bash
python -m http.server 8080
```

и откройте `http://localhost:8080`.

## Что умеет калькулятор

- до 20 мастеров, у каждого свой процент от услуги
- старые доходы не пересчитываются при смене процента
- мастера с доходами удалить нельзя
- журнал доходов и общих расходов, правка и удаление записей
- фильтр по датам, мастеру и услуге
- прибыль = выручка − выплаты мастерам − общие расходы
- резервная копия JSON и выгрузка CSV для Excel
